# הספר במסך מלא באייפון

באייפון, ספארי לא מאפשר לאתר להסתיר את שורת הכתובת. מסך מלא אמיתי מתקבל רק כשהספר נפתח מאייקון במסך הבית. יש שתי דרכים להגיע לזה:

## דרך 1: מערכת המחשוב מתקינה את האייקון לכולם (מומלץ)

הקובץ `hr-2030-webclip.mobileconfig` הוא פרופיל הגדרות סטנדרטי של אפל (Web Clip), עם הגדרה של מסך מלא.
מחלקת המחשוב מעלה אותו למערכת ניהול המכשירים של הארגון (MDM, למשל Intune, Jamf או Workspace ONE),
והאייקון "מש״א 2030" מופיע לבד במסך הבית בכל אייפון של עובד. מהלחיצה הראשונה הספר נפתח במסך מלא, בלי שורת כתובת.

- כתובת: https://clalit-hr.github.io/hr-2030/
- סוג הפרופיל: Web Clip, ‏FullScreen = true
- ב-Intune: Devices ← Configuration ← Create ← iOS/iPadOS ← Templates ← Custom, ומעלים את הקובץ.

## דרך 2: כל עובד מוסיף לבד, פעם אחת

בספארי: שיתוף (או ⋯ ואז שיתוף) ← "הוספה למסך הבית" ← פותחים מהאייקון.
הספר עצמו מציג את ההנחיה הזאת כשלוחצים באייפון על "מסך מלא".
