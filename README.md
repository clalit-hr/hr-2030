# אסטרטגיית מש״א 2030, ספר דיגיטלי

https://clalit-hr.github.io/hr-2030/

קובץ אחד (`index.html`) עם כל 12 השקפים בתוכו. דפדוף ספר, חפיסת קלפים או עומק, זום, תוכן עניינים, שיתוף לעמוד, דפדוף אוטומטי, מסך מלא וסיבוב לרוחב.

## עדכון הספר

1. מחליפים את קובץ ה-PDF בתיקייה (12 עמודים; אם מספר העמודים משתנה, מעדכנים את שמות העמודים ב-`build.py`).
2. `python build.py` (צריך `pip install pypdfium2 pillow`).
3. שומרים ודוחפים. GitHub Pages מפרסם לבד מהענף `main`.

עריכת העיצוב וההתנהגות: `src/template.html`. לא עורכים את `index.html` ישירות, הוא נוצר מחדש בכל בנייה.

מקשים במחשב: חצים, רווח, Home/End, ספרות לקפיצה, F מסך מלא, Z זום, P דפדוף אוטומטי, M צליל.

אייפון ומסך מלא: ראו `iphone/README.md`.
